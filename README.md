# Mindora — AI Study Assistant\n\nResponsive React + Vite study workspace featuring notes, flashcards, quiz practice, a focus timer, and a local study-guide helper. Data persists in localStorage. The helper is a frontend demo, not a connected AI service; connect a secure backend to enable real model responses.\n\n## Run locally\n```bash\nnpm install\nnpm run dev\n```\n\n## Build\n```bash\nnpm run build\n```\n\n## GitHub Pages\nRepository name: `ai-study-assistant`. Vite base path is configured for `/ai-study-assistant/`. The included GitHub Actions workflow builds and deploys the `dist` folder automatically. In GitHub, open Settings → Pages and choose **GitHub Actions** as the build and deployment source.
